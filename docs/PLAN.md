## 0. 一句話

一個**免帳號、純前端、離線可用**的 PWA，給「定期定額、長期持有、配息再投入、每天盤後看一眼」的**上市**股票投資人：記持股與每月變動，每個交易日結算**當日損益**，累積**已領股利**，顯示**除權息日曆**，整理國內外財經大事（標題＋連結），用**你自己的 Claude 金鑰**產生「今日觀察」（非投資建議），並附一個**定期定額試算器**（所有假設由你輸入）。

### 2.1 資料來源（全部已實測，見 FEASIBILITY.md）

| 需求 | 端點 | 方式 |
|---|---|---|
| 今日收盤（所有持股一次） | `www.twse.com.tw/rwd/zh/afterTrading/STOCK_DAY_ALL?response=json`（實際回 CSV，~320KB） | 前端直打，每日一次 |
| 回補缺漏日、前一交易日收盤 | `www.twse.com.tw/exchangeReport/STOCK_DAY?response=json&date=YYYYMMDD&stockNo=` | 前端直打，每檔每月一檔，≥ 2 秒間隔 |
| 除權息日曆（未來約 7 週） | `www.twse.com.tw/exchangeReport/TWT48U?response=json` | 前端直打，每次開頁一次 |
| 除息當天參考價、權值息值 | `www.twse.com.tw/exchangeReport/TWT49U?response=json&strDate=&endDate=` | 前端直打，只在有除息事件的期間查 |
| 大盤漲跌 | `www.twse.com.tw/rwd/zh/afterTrading/FMTQIK?response=json&date=` | 前端直打（按「產生今日觀察」時才打；不用 MI_INDEX 的理由見 `STATUS.md`） |
| 代號表、開休市日 | `openapi.twse.com.tw`（無 CORS）→ **建置腳本**產靜態檔 | 開發者手動執行，commit |
| 國內新聞 | 四個 RSS | 經 Worker `/rss` |
| 國際新聞 | `www.cnbc.com/id/10000664/device/rss/rss.html`、`feeds.content.dowjones.io/public/rss/mw_topstories` | 前端直打（有 ACAO *） |
| AI | `api.anthropic.com/v1/messages`，header `anthropic-dangerous-direct-browser-access: true` | 前端直打 |

### 2.2 開頁流程（自動更新一次）

1. 讀 `calendar.json` 與本機「上次結算日」，算出缺的交易日。
2. 只缺今天且現在已過「今日資料公布門檻」（M0 實測後定，暫定 15:00）→ 打一次 `STOCK_DAY_ALL`，抽持股代號 → 結算今天。
3. 缺多天 → 每檔持股打 `STOCK_DAY` 當月檔（跨月多打），≥ 2 秒一次、顯示進度；同時打 `TWT49U` 補這段期間的除權息結果。
4. 打一次 `TWT48U` 更新除權息日曆並對照持股。
5. 今天的資料還沒出來 → 顯示「今日收盤尚未公布（最後更新：M/D）」，**不顯示 0、不用昨天冒充今天**；可下拉重試（30 秒內只算一次）。
6. 有待確認事件（除權息、定期定額扣款、配息再投入）→ 首頁頂部提示。
7. 有金鑰且今天尚無「今日觀察」→ 抓新聞、產生觀察（10–20 秒，可背景等待）。
8. 全程離線 → 顯示上次結算結果並標示日期。

### 2.3 頻率保護
- TWSE 直打 ≥ 2 秒間隔、同檔同月只抓一次（IndexedDB 快取）；一次開頁最多 30 個 TWSE 請求，超過分批並提示。
- Worker 端每個來源 Cache API 10 分鐘；前端同一天同一來源 30 分鐘內不重抓。

### 2.4 不支援代號的處理
- 上櫃／興櫃 → 「6488 環球晶 是**上櫃**股票，這個版本只支援上市，**不會顯示價格與損益**」；可「仍然記錄股數（不計損益）」或取消。記錄的話該檔在所有畫面標「不支援報價」，不進當日損益與市值總和，不提供除權息；總和旁固定標「不含 N 檔不支援報價的持股」。
- 不在清單 → 「找不到這個代號」，顯示清單日期；**代號表超過 60 天時多講一句**
  「可能已經有新上市的代號沒收進來，請更新 App」。
  · ~~可「試著查一次」（打一次 `STOCK_DAY`），查得到就加入並標「未在清單」。~~
    **2026-09-17 決定不做**（`SPEC_全面優化.md` §4 B3，Yolin 拍板）：那會多出一種
    「未在清單」的持股，而**每一個畫面都要處理它** —— 產業分布沒有它的產業、
    集中度的分母要不要算它、匯出匯入要不要保留它、代號表更新之後要不要合併回去。
    收益是「偶爾能早幾週加進一檔新上市的股票」，成本是一整條平行的資料路徑。
  · 改成的替代方案：`catalog.staleness()` 純函式（門檻 `CATALOG_STALE_DAYS = 60`），
    設定頁的「來源」那一行與「找不到代號」的訊息各多一句。不打 `STOCK_DAY` 試查。
- 任何情況下不支援的代號**不得顯示任何價格**。

## 3. 資料模型（IndexedDB）

| store | 內容 | 說明 |
|---|---|---|
| `holdings` | `{code, name, market, shares, avgCost?, supported, costNote?}` | `shares` 由 `changes` 已確認項累加，不手改；`avgCost` 選填；`costNote` 例如「成本未含最近 2 次扣款」 |
| `changes` | `{id, code, date, deltaShares, price?, kind, note, status}` | 持股變動紀錄。`kind ∈ opening / manual / dca / dividendReinvest / stockDividend`；`status ∈ pending / confirmed`。「快速設定持股」＝一筆 `opening` |
| `plans` | `{id, code, amount, days[], feeRate?, reinvestDividend, active}` | 定期定額計畫 |
| `events` | `{id, code, exDate, kind, cashPerShare, stockPerThousand, refPrice?, sharesHeld, amountEst, amountActual?, status}` | 除權息事件；`kind ∈ cash / stock / both`；`status ∈ upcoming / pending / confirmed / dismissed` |
| `closes` | `{code, date, close, prevClose, change}` | 只存持股代號 |
| `settle` | `{date, dayPL, byCode[], marketValue, unrealized?, excludedCount, note}` | 每日結算；可整天重算 |
| `news` | `{date, items:[{id, title, link, source, publishedAt}]}` | 只存標題、連結、來源、時間；保留 14 天 |

| `settings` | 字級、當日損益含應收股利（預設開）、股利自動扣費（預設關）、今日資料公布門檻時間 | |

## 4. 每日結算與股利

| 指標 | 公式 | 需要均價？ | 位置 |
|---|---|---|---|
| **當日損益** | Σ 持股 × (今收 − 基準)，基準＝前一交易日收盤，**除權息日改用參考價**；＋當日除息的應收股利（預設開） | 否 | 首頁最上方 |
| 持股市值 | Σ 持股 × 今收 | 否 | 首頁 |
| **累積已領股利** | Σ 已確認事件的實收金額 | 否 | 總覽（醒目）；另有本年度、每檔、每月長條 |
| 未實現損益、報酬率 | Σ 持股 × (今收 − 均價)；÷ Σ 持股 × 均價 | **是** | 總覽，只在該檔有均價時出現；部分有填時標「僅含 N 檔」 |
| 含息總報酬 | 未實現 ＋ 累積股利 | 是 | 同上 |

除權息事件流程：
1. 每次開頁對照 `TWT48U`，持股中有未來除權息 → `upcoming`，進日曆：「9/14 除息，每股 0.125 元，預估 N 股 × 0.125 = X 元」。
2. 除息日結算時：從 `TWT49U` 取參考價，當日損益以參考價為基準並標「含除息調整」；事件轉 `pending`。
3. 使用者確認（可改實收金額；若開「自動扣費」則預填扣匯費 10 元、單筆 ≥ 20,000 元扣 2.11% 補充保費）→ `confirmed`，計入累積股利；若計畫開「配息再投入」→ 產生 `dividendReinvest` 待確認變動（以除息日後首個交易日收盤估股數）。
4. 除權（配股）：待確認顯示「每仟股配 X 股 → 約增加 N 股，餘數 M 股以現金找零」，確認後寫 `stockDividend` 變動。
5. 現金增資、減資、分割：只提示「請對照券商通知手動調整股數」，提供手動變動輸入。

均價更新：定期定額或再投入確認時**有填成交價**→ 均價＝(舊均價 × 舊股數 ＋ 價 × 新股數) ÷ 新股數；沒填 → 均價不變並寫 `costNote`。

## 5. 定期定額

- 計畫：代號、每次金額、扣款日（可多個，例如 6、16、26）、（選填）券商手續費率、配息再投入開關。
- 扣款日當天或之後第一次開 App → 產生 `changes(kind:'dca', status:'pending')`，股數＝`floor(金額 × (1 − 手續費率) ÷ 扣款日收盤)`，畫面顯示估算股數與餘額；使用者對照券商通知**一鍵確認**或改成實際股數／成交價。
- 沒開 App 的月份累積成多筆待確認，不消失、不自動確認。
- 每月工作量：每個計畫一次確認。

## 6. 定期定額試算器

定位：**假設情境的數學推算，不是預測。** 頁面頂部固定：「以下結果完全由你輸入的假設算出，不是預測，也不是建議。」

**輸入**（全部由使用者填，**預設空白，沒有建議值、常見值、歷史平均、範例值**）：
每期扣款金額；扣款頻率（每月 1／2／3 次）；期間（年）；年化價格成長率（%）；年化配息率（%）；配息頻率（年／半年／季／月）；配息再投入（開／關）；選填：目前已有部位（市值，或股數＋現價）、扣款手續費率（預設 0）、股利扣費（匯費 10 元／次、單次 ≥ 2 萬扣 2.11%，預設關）。

**輸出**：期末市值、累積投入、累積配息（再投入時為已再投入金額）、逐年表、投入 vs 市值折線。「配息再投入」與「配息領現」兩情境並排，命名為「你的假設 A／B」，**不出現「預期」「保守」「樂觀」「建議」字樣**。

**AI 完全不介入**：不預填、不解讀、不評語、不出現在這一頁。

**零股與未滿一股**：
- 預設**金額法**：市值 × 成長率、市值 × 配息率，全程高精度小數（用整數「分」或 BigInt 微元計算），**不做任何捨入**，只在顯示時取到元。
- 切換**股數法**：需輸入目前股價；每期 `股數 = floor(可用現金 ÷ 當期股價)`，**買不足的餘額結轉下期**（不捨棄、不四捨五入），配息進同一現金池。畫面標示「兩種方式期末差距小於一股的價格」。
- 不模擬整張限制。

## 7. 新聞與「今日觀察」

### 7.1 新聞
- 國內（經 Worker）：中央社財經、鉅亨台股、自由財經、Yahoo 股市。國際（直打）：CNBC、MarketWatch。
- 只存標題、連結、來源、時間；不抓文章頁、不存摘要、不重製全文；點擊開原站。
- 前端做「與我持股相關」標記（代號、公司簡稱、產業關鍵字）。

### 7.2 今日觀察的界線
定位：**資訊整理與觀察，不是投資建議。** 寫進系統提示、UI、測試三處。

可以：新聞與持股的關聯與原因（供應鏈、客戶、同業、利率、匯率、政策）；新聞中已陳述的事實；歷史上類似事件的市場反應（必須標「過去不代表未來」）；值得留意的日期（法說、財報、除息、FOMC、CPI）；持股集中度提醒；資訊不確定之處。

不可以：買／賣／加碼／減碼／停損／停利／進場／出場；目標價、支撐壓力；預測任何期間漲跌；對個股「看好／看壞」；「建議」「應該」「值得」開頭的句子；比較個股優劣；引用未提供的新聞。

輸入：新聞標題（帶編號）、持股代號＋名稱＋產業＋當日漲跌％、大盤漲跌％、日期。**不給股數、不給金額、不給成本。**

輸出：`output_config.format` 要求 JSON `{summary, sections:[{theme, newsIds[], relatedCodes[], observation}], watchDates[]}`；前端只渲染結構。

程式端防線：輸出後以禁用詞正則掃描（建議買／賣、加碼、減碼、目標價、看漲／看跌、停損、應該買…），命中的段落**整段不顯示**並標「AI 越界，已隱藏」，可按「重新產生」。測試必須有**對照組**。

UI：區塊標題固定「今日觀察（AI 整理，非投資建議）」，灰底標籤不可關閉；每段列引用的新聞編號可點回原文；底部固定「由 Claude（模型名）依新聞標題於 HH:MM 產生，未經查證，不構成投資建議」；AI 文字不用紅綠色、不用箭頭。首次啟用一次性說明頁（不是投資建議；金鑰與費用由你付；金鑰只存這台手機），需勾選才啟用。

### 7.3 金鑰與模型
- 設定頁：`type=password` 欄位＋「貼上」鈕、前綴 `sk-ant-` 驗證、一次最小呼叫測試、之後只顯示遮罩、清除鈕（並提醒到 Anthropic 後台 Delete 才是真停用）。
- 預設 `claude-sonnet-5`；可選 `claude-opus-5`、`claude-haiku-4-5`。
- 用量：每次回應的 `usage` 乘費率累加成微美金，設定頁顯示「本月約 $X」；達使用者設的上限（預設 $2）即停用並提示。真正的硬上限是 Anthropic 後台的 Billing 上限，設定頁提醒。
- 所有 AI 輸出與錯誤訊息顯示前以 `/sk-ant-[A-Za-z0-9_-]+/` 洗掉。

## 10. 不做什麼

| 不做 | 原因 |
|---|---|
| 上櫃／興櫃報價 | 使用者決定；櫃買擋前端與 Cloudflare Worker |
| 盤中即時、自動輪詢 | 只在盤後看 |
| 已實現損益、手續費、證交稅 | 使用者決定 |
| 券商帳號密碼、下單、轉帳、任何連券商的功能 | 使用者明訂；不規劃也不實作 |
| 帳號、雲端同步持股 | 單一使用者；匯出 JSON 即可換機 |
| AI 選股、評分、健康度、預期報酬率建議值 | 屬投資建議 |
| 抓文章全文、udn 系列、Google News、NYT | 版權／robots／封鎖／條款 |
| 推播 | iOS PWA 推播不可靠；開頁即見待確認事件 |
| 技術分析、K 線 | 不是目的，容易滑向建議 |
