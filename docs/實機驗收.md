## 0. v0.7.9 新改的（你回報的那兩項，請先看這裡）

### 0-1. 持股頁的排版（你回報「跑版」的那一頁）

整頁重做了排版方式：每一列右邊的損益現在有自己的固定欄位，不會再被左邊的名字擠到下一行。

- [ ] 每一列是不是**都一樣高**、右邊的數字**上下對齊成一直線**？
- [ ] 4 碼（2330）與 5 碼（00878）的代號是不是對齊的？
- [ ] 名字太長時是不是變成「元大台…」而不是換行或被切掉？

**怎樣算過**：七列看起來像一張整齊的表，沒有哪一列特別高。

### 0-2. 小螢幕＋大字級（只有 iPhone SE／mini 需要試）

如果你的手機是 SE 或 mini（螢幕比較窄）：設定 → 字級 → 大或特大，再回持股頁。

- [ ] 每一列的「均價」與產業標籤（半導體業…）會**刻意隱藏**——這是設計，不是壞掉
- [ ] 但當日損益與漲跌％**一定要在**

**怎樣算過**：數字都在、沒有任何兩段字疊在一起。
**為什麼這樣設計**：那個尺寸下左邊真的放不下，寧可少顯示兩個次要資訊，也不要讓數字疊在一起。均價在點進單一檔之後看得到。

### 0-3. 試算「從你自己的資料帶入」（你說「請自動帶出相關欄位」的那一項）

試算頁最上面多了一張「從你自己的資料帶入」。

1. 按你其中一個計畫的按鈕（按鈕上會寫那個計畫的代號、名稱與每期金額）
2. **要看什麼**：下面的欄位應該自動填好 —— 每期扣款金額、每月扣款次數、手續費率、目前已有部位的市值
3. **但「年化價格成長率」與「年化配息率」必須還是空的**
4. 卡片上應該寫著：「沒有帶入：年化價格成長率、年化配息率。那兩個是對未來的假設……」

**怎樣算過**：第 2 步該填的都填了，第 3 步那兩格**確實是空的**。
**為什麼不幫你填那兩格**：那是對未來的預測。填了等於這個 App 替你做投資判斷 —— 這條界線不會因為方便而讓步。

- [ ] 順便試：手續費率欄位輸入 `0.1425`，下面應該立刻出現紅字擋下來（跟定期定額那一頁一樣）
- [ ] 按「算一次」之後，畫面應該**自動捲到結果**，不必自己往下找

## E. 這一版應該看得到的變化（順便確認沒改壞）

不是我沒把握的項目，是給你對照用的：

| 在哪裡 | 應該變成什麼樣 |
|---|---|
| 持股頁 | 每一列右邊多了**當日損益與漲跌％**；卡片上方寫著「下面的當日損益是 X/X 收盤結算的」 |
| 持股頁 | 「目前持股」跑到「產業分布」**上面**了 |
| 持股頁 → 產業分布 | 你持有的 ETF 那幾檔歸在「**ETF**」，不再叫「產業未知」 |
| 點進單一檔持股 | 卡片標題從「目前」變成「**X/X 收盤**」 |
| 定期定額 → 修改計畫 | 手續費率欄位下面會**當場算給你看**：「0.001425 ＝ 0.1425%，這一次扣款 5,000 元會收 7.13 元手續費」 |
| 定期定額 → 計畫列 | 「修改」「停用」固定在自己一行、右對齊，不會因為有「配息再投入」標籤就跑位 |
| 新聞頁 | 標題與來源改成**靠左**（以前是置中） |

### E1. 順便試一下手續費率（你三個計畫現在都是「無手續費率」）

這一項你遲早會填到，而且**填錯一個單位會讓估出來的股數少一成四**（5,000 元買 0050：46 股變 39 股），畫面上還看不出來。

- [ ] 定期定額 → 隨便一個計畫 → 修改 → 手續費率欄位輸入 `0.1425`
- [ ] 應該會**立刻**在下面出現紅字：「0.1425 代表 14.2500%，看起來是把百分比直接填進來了。券商說的『0.1425%』要填 0.001425。」
- [ ] 改成 `0.001425`，下面應該變成「0.001425 ＝ 0.1425%，這一次扣款 X 元會收 Y 元手續費」
- [ ] 按「儲存」，計畫列上應該寫「手續費率 0.1425%（每次約 Y 元）」

你的券商實際費率是多少要看對帳單 —— 我**不會**替你填任何數字。
